Awesome Inc workspace virtual tour

Pannellum JavaScript Gatsby 360° panorama

Context: Internship project at Awesome Inc — the team wanted a virtual 3D-style tour of the coworking space for visitors who could not visit in person.

What I did: Built a multi-scene panoramic tour with Pannellum, wired scene-to-scene navigation (coworking, hallway, kitchen, and more), and configured hotspots so users can click doorways to move between spaces.

Outcome: A live Netlify preview reviewers can drag through in the browser, plus a pull request on Awesome Inc’s Gatsby site for integration.

Top 5 scorecard

React TypeScript Supabase AG Grid

Context: Awesome Inc ran the Top 5 weekday challenge in a Google Sheet. People needed a board they could check off, with scoring, streaks, and roles so only the right person edits a row.

What I did: Built a Vite + React app with Google sign-in, Postgres behind Supabase (row-level security), pages for My week, Dashboard, Leaderboard, Streaks, and Admin, plus CSV import from the old sheet. Signed-out visitors can read the board; members edit their own tasks.

Outcome: Live at top-5-web-app.netlify.app. Checking all five tasks turns on the Top 5 bonus; the database enforces who can write.

Local IT health report

PowerShell CIM Windows Event Log CSV

Context: Other PowerShell in this repo talks to a file share, SharePoint, or WSUS. This one runs on any Windows PC — the “how would you check a box quickly?” answer for ICT work.

What I did: Collect machine and OS facts, local disk free space, automatic services that are stopped, and recent Application/System errors. Write UTF-8 CSV and a simple HTML summary next to the script.

Outcome: A report you can open in Excel or a browser and schedule with Task Scheduler. SharePoint, NTFS, and WSUS scripts stay in the same folder as environment-specific jobs.
